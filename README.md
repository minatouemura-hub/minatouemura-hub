## Current Research

### Multimodal Emotion Concept Learning

I am investigating how emotion-related concepts can emerge through the integration of multiple modalities:

```text
Physiological Signals
        │
        ├── RRI
        └── EDA
        │
        ▼
  Multimodal Model  ◄──── Audio
        ▲
        │
      Language
        │
        ▼
 Emotion Concepts
```

The goal is to model relationships between **interoceptive**, **exteroceptive**, and **linguistic information** using probabilistic multimodal learning.
